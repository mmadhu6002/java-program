# Java Programming Assignment

This repository contains **20 Java programs** for practicing basic programming and problem-solving concepts.

### Programs Included

* Fizz Buzz
* Palindrome Number
* Add Digits
* Number of 1 Bits
* Count Digits That Divide a Number
* Steps to Reduce Number to Zero
* Find Common Factors
* Add Binary
* Binary to Integer
* Reverse String
* Length of Last Word
* Longest Common Prefix
* Valid Palindrome
* Detect Capital
* Reverse Prefix of Word
* Equivalent String Arrays
* Goal Parser Interpretation
* Defanging an IP Address
* To Lower Case

### Concepts Covered

Java basics, loops, conditions, numbers, strings, arrays, and bitwise operations.

**Language:** Java
**Purpose:** Learning and practicing Java programming.
